HONEST INTERPRETATION OF RESULTS
  Permutation importance shows 'description_length' carries 100% of the model's discriminative signal.
  ROC-AUC is ~1.0 because a SINGLE structural feature separates the
  classes almost perfectly. This is a DATASET ARTIFACT, not evidence
  of generalizable fraud detection: in the current labeled set the
  fraud examples (flagged / scraped junk entries) systematically
  differ in 'description_length' from the curated legitimate scholarships —
  i.e. the two classes come from different SOURCES. The model learns
  the source gap, not fraud semantics.

  HONEST CONCLUSION (defend this in the viva):
    • The rule layer (keywords + suspicious TLD + URL checks) remains
      the PRIMARY, reliable fraud detector.
    • The ML layer is a WEAK auxiliary signal on this dataset and
      should not be presented as an independently-validated classifier.
    • A trustworthy supervised model needs fraud AND legit examples
      drawn from the SAME source, with human-verified labels, then
      re-evaluated on a held-out test set.
